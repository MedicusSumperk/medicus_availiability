# Archive

This directory is intentionally ignored by Git for new files. It is used for
historical artefacts that should stay available locally but should not shape the
active backend context.

Current archive groups:

```text
archive/elevenlabs/
  Historical ElevenLabs prompts, exports, tool configs, dynamic-variable
  experiments, and live-test artefacts.

archive/config-examples/
  Old config examples that are no longer runtime config.
```

Active source-of-truth documentation stays in `docs/`. Database research that
still informs backend behavior lives in `research/`, not here.
